# US13 — Накопление к выбранной дате

Дата: 17.10.2026. Область: Фаза 15, T103–T108; ФТ-040–041, КУ-010.

## Реализация

Добавлены savings_plan, SQL migration us13_savings-plan, journal и Drizzle snapshot. Одна конфигурация на scoped goal, composite FK ON DELETE RESTRICT, DATE и исходное число месяца, finite nonnegative NUMERIC без typmod, bigint version. Масштаб проверяется по сохранённой валюте цели. Смена валюты цели с сохранённым планом отклоняется, чтобы взнос не приобрёл другую валюту неявно.

Domain savingsProjection использует Decimal с динамической точностью, рекомендации ROUND_CEIL и общие календарные helpers. Остаточные даты считаются от исходной даты до срока включительно, без перебора длинного расписания. После февраля возвращается исходное число. Прогноз использует первый будущий взнос и ceil(remaining/contribution), обозначает опоздание. Нулевой/отсутствующий взнос не обещает дату. Reached, no_obligation, expired, no_dates и no_deadline имеют явные состояния. Прогноз за пределами представимого календаря возвращает null и явный признак, не ограничивая сумму плана.

Configure проходит shared financialTransaction: актуальные права и locks, idempotency receipt, optimistic version, audit в одной транзакции. До создания конфигурации expectedVersion отсутствует; первая сохранённая version=1, последующие изменения требуют актуальную version. Read/replay заново строят scoped результат по текущему балансу и условиям цели. Новая anchorDate не раньше сегодня; прежняя сохранённая дата может оставаться неизменной при редактировании суммы, сохраняя исходное число. Часовой пояс — профиль для personal, workspace для family. Ledger и баланс не изменяются.

Dynamic/no-store страница целей читает планы в общем согласованном snapshot. Форма React Hook Form/Zod: русские подписи, pending/error/focus, защита несохранённых данных и безопасный retry после потери ответа. Серверный предпросмотр с задержкой 350 мс пересчитывает изменённый ввод без сохранения и создания операций; устаревшие ответы игнорируются. В React нет денежных расчётов.
