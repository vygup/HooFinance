# US15 — Главный дашборд (Фаза 18)

Дата: 2026-10-20. Область: T121–T126, ФТ-047–048,062; КУ-012.

## Реализация

- `/dashboard` после входа и `/w/[workspaceId]` показывают общий остаток по валютам,
  счета, месячные доходы/расходы, бюджет, цели, резервы, последние пять действий
  и предстоящие платежи. Карточки ведут к данным того же пространства; для счетов
  и целей добавлены якоря. Переключатель сохраняет раздел обзора без старых фильтров.
- Строгий Zod DTO требует workspaceId, не принимает actor или произвольный месяц.
  Необязательные парные границы относятся только к платежам и сохраняют прежний
  сценарий выбора интервала на `/dashboard`. Месяц определяет сервер по поясу семьи
  или профиля пользователя.
- Все карточки нового обзора читаются в одной авторизованной read-only транзакции
  repeatable read. Используются существующие счета, бюджет, цели и расписания;
  новых таблиц и миграций нет. Чтение не создаёт receipt, audit или версии:
  существующий financial executor применяется только к изменениям.
- Остатки используют точные Decimal-строки. Цели, резервы и архивные счета входят
  в сумму через счета ровно один раз. Валюты не складываются между собой.
  Доходы/расходы и бюджетный факт используют текущие активные ревизии;
  переводы и начальные остатки исключены. Исправление и удаление отражаются при чтении.
- Последние действия выбираются с DISTINCT до LIMIT; обе локальные стороны перевода
  показываются одним действием. Репозиторий возвращает только разрешённые поля
  выбранного пространства, без противоположной стороны, account audit и edit DTO.
- Платежи подключены к реализованной US14. Общие schedulePayments и история расписаний
  вычисляют непросмотренную просрочку и будущие даты без материализации экземпляров
  или расходов при просмотре. Прежний readDashboard для платежей сохранён совместимым.
- React Hook Form/Zod, русские подписи, отдельные план/факт и пустые состояния,
  доступный focus, loading/error/retry. При отказе в доступе во время обновления
  финансовые карточки убираются. Денежной арифметики в React нет. Страницы dynamic,
  общий персональный cache не добавлен.

## Проверки

Временная PostgreSQL без опубликованных портов, отдельная тестовая БД,
случайные тестовые секреты и локальный SMTP fixture без внешней доставки.
Локальные Next.js guides use-server, page и data-security прочитаны до кода.
